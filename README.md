## 👨‍💻 About Me

I'm **Elmehdi Khardi**, an aspiring software engineer from **Rabat, Morocco**. I enjoy building practical, full-stack applications and turning ideas into clean, useful experiences.

I am especially interested in backend development, relational database design, authentication, and building secure applications with clear role-based permissions. I am continuously strengthening my skills through hands-on projects with JavaScript, React, Node.js, Express, and PostgreSQL, while also learning the Java ecosystem with JavaFX and Spring Boot.
